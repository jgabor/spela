First public release of spela. Includes release automation, documentation, and workflow updates.

## Release workflow design

Automated release pipeline designed in brainstorming session:

- **Trigger**: `mage release` CLI command (manual trigger, auto-versioning)
- **Version**: Computed from conventional commits via git-cliff
- **Changelog**: keepachangelog format, generated by git-cliff
- **Summary**: LLM-generated intro via opencode CLI (fallback to manual)
- **Confirmation**: Preview with [1] Proceed [2] Edit [3] Abort
- **CI**: GitHub Actions builds AMD64 binary, extracts release notes from CHANGELOG.md

## Goals

- Establish release process and automation via Magefile
- Create comprehensive documentation
- Generate changelog from commit history using git-cliff
- Ensure CI/CD pipeline is fully functional

## Success criteria

1. `mage release` computes version, generates changelog, and pushes tag
2. `v0.1.0` tag triggers successful release workflow
3. GitHub release includes binary, checksums, and release notes from CHANGELOG.md
4. README.md documents installation and usage
5. CHANGELOG.md tracks version history in keepachangelog format
