# Mock frames for the three alternatives

Generated by `synthesis/mocks.py` in the review evidence folder, which checks every line's
display width and the row count of each frame (120x40 or 80x24). They are drawings of the
proposed screens, not captures of a running program. The scenario is Cyberpunk 2077 from the
review fixture: HDR, VKD3D heap (same as All games), Super resolution, Frame generation, and
Clock offset are its own values. Companion to
[tui-profile-settings-ux-review.md](tui-profile-settings-ux-review.md).

Row tallies use the review's `tally-rows.py` (content, chrome, empty dialog space, empty pane).
The baseline game Profile frame at 120x40 is 23 / 15 / 0 / 2. Frames with a dialog drawn over
the page are not tallied because the tool reads the dialog border as a pane.
